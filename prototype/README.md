# Site Scout local screening preview

From the repository root, run `python3 -m http.server 4173 --bind 127.0.0.1`, then open `http://127.0.0.1:4173/prototype/`. The page uses only local files and makes no live API requests; outbound source links open if selected. Run `npm test -- --run tests/prototype-data.test.ts tests/prototype-factor-readiness.test.ts tests/prototype-failure.test.ts tests/prototype-journey.test.ts tests/prototype-scenario.test.ts tests/prototype-memo.test.ts` after changing its snapshot, factor leads, or sample inputs.

The page starts with blank owner input, then a dated, sampled map and an abstaining owner-area screen. A separate Punggol replay below is an optional synthetic example. The plotted positions come from the reviewed HDB/OneMap records. The plot has no basemap, walking routes, catchment boundaries, or verified market ranking. Sample figures are never owner input or grounds for a real recommendation. The decision remains `insufficient_evidence`. The replay status path shows evidence stages, not live agent activity.

The separate interactive coordinate map shows three sampled investigation priorities across Queenstown, Ang Mo Kio and Marine Parade, each with three checked block points and dated OneMap/HDB links. The islandwide explorer below shows all 27 HDB contract-town codes, 162 checked address points and 86 sampled three-block groups across 26 codes from dated authenticated OneMap replays. The feed is pinned to reviewed bytes; a missing or changed feed is withheld. The order uses published housing stock to decide what to investigate first, not business suitability. Another 10,647 HDB leads remain unprobed, eight probes were unresolved, KWN still has no checked group, and all 27 whole towns are unassessed. Run `npm test -- --run tests/prototype-priority-map.test.ts tests/prototype-national-explorer.test.ts` for the exact-join, status and interaction checks.

The owner form starts blank and accepts the business owner's own confirmed estimates for **group reformer Pilates**. Other formats, including tuition and F&B, are rejected before the class-only calculation; they need separate models. Once confirmed, selecting a sampled block group and changing paid-seat utilisation updates a screen at the owner's rent ceiling and a copyable memo with source dates and evidence status. Editing any owner field requires reconfirmation. This remains an `insufficient_evidence` screening result, not a lease recommendation; the separate Punggol sample scenario below is explicitly synthetic. Run `npm test -- --run tests/owner-journey.test.ts tests/owner-intake.test.ts` for this connected path.

The editable scenario changes seats, weekly classes, realised visit revenue, assumed rent, paid-seat utilisation, and opening month. It calculates the class-only operating result locally and parity tests its browser projection against the deterministic engine. The assumed month-24 occupancy start is imaginary and not a Punggol development forecast. Financial feasibility cannot turn the location result positive while cluster-level market and premises evidence is missing. The review memo mirrors the current synthetic inputs and class-only result, lists all three unranked block groups with retrieval dates and per-block source links, and names the first premises check; invalid inputs hide the memo result.

The corresponding offline, source-bound point collection is `src/data/snapshots/2026-10-06/places.geojson`. Run `npm test -- --run tests/map-snapshot.test.ts` to check it against the integrity-checked cluster originals and reject unsupported joins.

The six factor cards summarize earlier Gate 2 research on rent, premises use, competitors, access, demographics, and future housing. They cite their own source and retrieval date, identify their geographic scope, and remain `research_only` with no cluster linkage. They are not normalized usable evidence records or current unit approvals; see `outputs/SOURCE_REGISTER.md` and the factor-specific audits for access and rights limits. If the local feed is missing or malformed, the page hides the factor cards along with the block evidence.
