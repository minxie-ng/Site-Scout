# Site Scout — judge walkthrough

Use the deployed [Site Scout demo](https://sitescoutsg.vercel.app/) and [public GitHub repository](https://github.com/minxie-ng/Site-Scout). This is a sampled, abstaining screening product for a group reformer Pilates operator, not a current lease recommendation. Allow about 90 seconds for the recorded presentation; a live provider run may take longer and requires the private demo access code.

1. **The business starts the study.** Show the blank owner form. Enter clearly labelled *illustrative estimates*: S$35 per paid visit, 10 seats, 30 classes per week, S$3 variable cost per visit, S$65 instructor cost per class, S$5,000 other monthly costs, S$13,000 rent ceiling, S$50,000 opening budget, six months runway and opening in three months. Enter “Group reformer Pilates,” “Adults near transit,” and “None — demo” in the text fields. Confirm the estimates. The inputs stay in the browser; these figures do not establish customer demand. Screenshot: [owner start](devpost/01-owner-start.jpg) and [blank input form](devpost/02-owner-input.jpg).
2. **Choose a specific checked area.** Scroll to the Queenstown, Ang Mo Kio and Marine Parade map and select Queenstown Blocks 1, 2 and 3 on Ghim Moh Road. Open the OneMap and HDB links beside a block and point out their retrieval dates. The 658 published dwellings are a derived housing-stock priority, not occupied homes or a national best-site score. The page reports 162 checked address points, 86 sampled three-block groups in 26 HDB codes, 10,647 unprobed leads, eight unresolved probes and 27 whole towns unassessed. Screenshot: [checked area map](devpost/03-checked-area.jpg).
3. **See what the numbers can and cannot answer.** At 60% assumed paid-seat utilisation, the owner scenario is below its class-only break-even requirement of 827 paid visits/month (63.7% average utilisation) at the entered rent ceiling. Site Scout withholds the real-area recommendation because no exact available unit, current rent, permitted Pilates use, walking access, local competition or demand has been verified. The copyable memo preserves the block URLs, dates and limitations. Screenshot: [abstaining owner result](devpost/04-abstaining-result.jpg).
4. **Show bounded live research.** With the private demo access code, press “Investigate selected group.” The deployed server checks the selected group digest, uses actual Jev Decisions to order the `area`, `market` and `challenger` roles, and streams observed stages. The roles inspect three prechecked block facts; they do not discover new verified sources or approve a site. If the code is wrong or the provider fails, the page keeps the checked map and local scenario available and labels the degraded state. Screenshot: [rejected access fallback](devpost/05-access-failure.jpg). Keep the code out of screenshots and the public write-up.

The same-case paid comparison used the same Queenstown group, three prechecked facts and three role calls per arm. Fixed order took **3.735 s** and reported **US$0.000069572**; Jev order took **10.096 s** and reported **US$0.000089138**. Both returned `insufficient_evidence`. The production Jev smoke run took **8.963 s** and reported **US$0.000078896**. Jev is integrated for bounded task ordering, but these measurements do **not** show a speed gain. The [credential-free comparison record](OWNER_LIVE_PAIRED_2026-10-13T12-36-43-275Z.json) contains the exact case and call counts.

Suggested closing line: “Site Scout makes a business owner's assumptions and dated block evidence inspectable, then shows exactly why a real expansion choice is still open. The next evidence needed is a specific available unit with verified rent, size and permitted use.”

Submission checklist: GitHub repo; deployed project link; illustrated Devpost write-up. The private live code should be supplied only to judges if a live provider demonstration is planned. The static owner screening and evidence map do not require it.
