# Site Scout MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a dependable Singapore HDB block-cluster screening advisor for a real Pilates operator's investigation decisions. The synthetic reformer profile is a labelled fixture for testing and demonstration, not a substitute for owner-confirmed inputs.

**Architecture:** A Next.js application reads versioned evidence snapshots and user assumptions, runs deterministic spatial and financial scenarios, and invokes bounded AI adapters for research synthesis and claim checking. The UI shows three named HDB block clusters on a map with timeline scenarios, evidence provenance, and investigate / wait / no-go / insufficient-evidence decisions. Live MCP connectors refresh evidence when available; the judged demo remains reproducible from a labelled snapshot.

**Tech Stack:** Next.js with TypeScript, Zod, Vitest, MapLibre GL, pure deterministic point-spatial functions (Turf.js only if later validated geometry warrants it), a small checked-in JSON/GeoJSON demo snapshot, Vercel Hobby for personal hackathon hosting, OpenRouter-compatible general LLM adapter, and optional direct TypeSafe Jev adapter.

**Current handoff (7 October 2026):** Gate 2 source feasibility is closed; Gate 3 remains open. Pure economics, spatial rules, synthetic scenario arithmetic, and a reviewed all-abstain real-cluster path plus synthetic-only decision fixtures are implemented. The next unchecked task is portfolio-level hard constraints and abstention. See the latest session note at the end of this file; older notes document their own historical status and do not override this handoff.
